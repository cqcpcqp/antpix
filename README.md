# antpix · 生态蚂蚁窝

Cocos Creator **3.8.8** / TypeScript / 微信小游戏。当前版本包含 100 幅已验收的 AI 原创画作，每关 48×60、2880 个像素。微信端使用 CloudBase 云存档、世界榜与好友榜，非微信环境支持本地试玩。

## 版本管理

当前项目版本为 **0.2.0**，以根目录 `package.json` 的 `version` 为准，Git 标签格式为 `vX.Y.Z`。升级步骤见 [版本管理](docs/versioning.md)，每版变更记录在 [更新日志](CHANGELOG.md)。

## 开发入口

1. 使用 Cocos Dashboard 导入项目，以 Creator 3.8.8 打开 `assets/scenes/Main.scene`。UI 由组件在运行时创建。
2. 使用 Node.js 24 执行源码检查和构建。先执行 `npm ci` 安装开发依赖；类型检查使用本机 Cocos 工具链。
3. 微信开发者工具导入 `build/wechatgame` 试玩；云函数部署入口为根目录 `project.config.json`。

```sh
npm ci
npm run format
npm run lint
npm run check
WECHAT_APPID=wxd8e27ad9cd0289df npm run build:wechat
```

默认 Creator 位于 `/Applications/Cocos/Creator/3.8.8/CocosCreator.app`。可通过 `COCOS_CREATOR` 指定可执行文件，通过 `COCOS_RESOURCES` 指定 Resources 目录。未配置 AppID 时，构建结果使用已有构建配置或游客配置；真机预览和上传需有效 AppID。

微信环境需要部署 `game` 云函数；配置、接口、数据库权限与部署命令见 [云开发指南](docs/cloud-development.md)。构建不会自动部署云函数。

## 当前玩法

- 100 关顺序解锁，每页 10 关，已完成关卡可以重玩。色数阶段为第 1–30 关 10–12 色、第 31–70 关 13–18 色、第 71–100 关 19–24 色。
- 待选容器使用离线规划的五条纵向队列，逐个模拟生成并减少同色重复；后续关卡含少量跨颜色收集依赖。只能点击每列第一张，第二张仅作预览。选择后仅该列上移；打乱只交换整列位置，保留列内顺序。
- 五个基础收集槽独立派工，1 倍速下每个容器每 0.5 秒可派出一只蚂蚁；不另设在途数量上限。可通过激励视频获取二倍速或额外槽位。
- 派出时预订目标并扣减容器数字，最后一次派出立即释放槽位；像素在蚂蚁抵达并能接触时才移除，回到公共洞口后才计入送达。旧蚂蚁按原容器 ID 结算。
- 可取像素必须有正交侧面连通底部入口。预计棋盘允许提前预订后续任务，实际移动仍检查真实棋盘，不穿越尚未取走的像素；寻路允许八方向移动但禁止穿越障碍对角。
- 长按容器查看整幅画中剩余同色像素，松手结束；滑动或切后台会取消查看。
- 全部像素送达后通关，先保存成绩和奖励，再播放约 3 秒的画作重组动画。满槽且无法继续时可重开或返回主页；在途任务未完成时不会提前判负。
- 同一运行会话可从主页继续当前关卡；关闭程序后从关卡开头开始，不保存关内棋盘。弹窗和后台状态暂停搬运。

## 存档、奖励与装修

微信端由服务端结算每日 30 金币、每关首次通关 100 金币及装扮购买；非微信试玩使用本地存档。目录版本为 4，追加关卡保留已有进度、金币、装扮和成绩。

首页庭院有门廊、小路、花园、生活角四个位置，每类三件装饰。商品支持预览、购买、布置与收起；未购买预览不保存，已拥有装饰可免费切换。局内洞口装扮使用独立入口。世界榜与好友榜规则见云开发指南。

## 目录

| 目录                         | 内容                                               |
| ---------------------------- | -------------------------------------------------- |
| `assets/`                    | 当前场景、业务源码、运行资源与 Cocos `.meta`       |
| `cloudfunctions/`、`wechat/` | 云函数、数据库配置、开放数据域                     |
| `scripts/`、`tests/`         | 当前构建、素材加工、无界面回归与性能工具           |
| `art/`                       | 当前素材源文件、已验收像素图、许可和容器规划报告   |
| `docs/`                      | 开发规范、素材流程、接口说明、图片约束及待解决问题 |
| `settings/`                  | 共享 Cocos 项目设置                                |

`build/`、`library/`、`temp/`、`profiles/` 为本地生成内容，不提交 Git；不要手改其中的业务产物。素材源文件与运行资源都应提交，不能只提交运行图片而丢失加工输入。

## 检查与素材维护

```sh
npm test
npm run typecheck
npm run check:ui
npm run check:built
npm run bench:animation
npm run bench:dispatch
```

`check:built` 需要已构建的微信产物；`build:wechat` 会自动运行产物回归。性能工具使用模拟渲染器，不能代替真机 FPS、GPU 和触摸测试。未在对话中获准时不得打开浏览器测试。
