# 关卡图片生成 Memory

更新时间：2026-10-13

状态：核心约束及 100 关色数阶段已通过问答确认，可用于后续生成。

## 已确认的约束

- 所有关卡图片都使用 AI 生成。
- 主体类型不限于小动物：动物、人物、物品均可；不再将“小动物半身像”作为统一限制。
- 关卡题材交替变化，动物、人物、物品穿插安排，避免连续多关过于相似；不要求按固定顺序循环。
- 整体氛围保持轻松明快：可以可爱、清新或有趣，不要求所有主体都萌化。
- 画风不限定：扁平卡通、柔和立体绘本、像素风均可，优先满足色数控制与像素化后的辨识度。
- 颜色数量必须受控，以最终用于关卡的像素图为准：前期 10–12 色，中期 13–18 色，后期 19–24 色；按阶段递增，阶段内允许起伏，不要求每关都比上一关增加颜色。
- 100 关色数阶段：第 1–30 关 10–12 色、第 31–70 关 13–18 色、第 71–100 关 19–24 色。阶段内允许起伏；具体题材与顺序仍须看图验收。
- 配色明快，颜色之间区分清楚，避免过多相近色，方便辨认画面和游戏中选色。
- 像素化后仍应能辨认原图的主体和主要形象特征，不能只看原图好看就通过验收。
- 每张候选图生成后，展示原图与按对应阶段目标色数转换的 48×60 像素图，进行并排对比；用户看过并明确确认后，才可将该图用于关卡。生成成功或自动检查通过不等于用户验收通过。
- 图片必须有明确主体，不允许纯风景。
- 后续关卡原图按 48×60 的目标网格来设计与验收，构图、主体轮廓和关键细节应优先保证在 48×60 像素化后清晰可辨。
- 每张图保持一个清晰的视觉中心，允许由多个对象共同组成（例如一对动物、一组茶具）；不要求只能有一个对象。
- 构图以显眼的主体为重点，同时留出环境空间；像素化后既能看清主体，也能辨认周围的小场景。不固定具体占比。
- 不接受纯色背景；允许简单装饰背景或简化场景背景，仍须保证主体明确、像素化后可辨认。
- 不直接使用有版权的知名 IP 角色。
- 不出现文字、数字、Logo、水印或装饰边框，包括题材中的招牌文字、钟表数字等。
- 通过逐轮问答确定其余约束；用户确认后再写入本节，不将建议或历史素材当作已确认要求。

## 后续评估与未设定细则

以下不属于新增硬性约束，不阻碍按已确认要求制作候选图；有必要时再结合具体生成任务或样图确认。

1. 难度阶段：100 关色数阶段已确认；可玩难度仍需结合像素化效果与试玩评估，色数不等同于实际难度。
2. 构图细则：一个视觉中心、可由多个对象组成，以及主体显眼并留出环境空间已确认；是否额外限定朝向、取景范围和边缘留白待确认，具体占比未设硬性数值。
3. 题材细则：动物、人物、物品各类题材是否有其他限制；整体轻松明快的基调已确认。
4. 背景：简单装饰与简化场景均可，纯色背景已排除；是否随关卡阶段增加背景复杂度待确认。
5. 色彩细则：明快、颜色区分清楚、避免过多相近色及分阶段色数范围已确认；是否限制跨关配色重复待确认。
6. 输出与验收：原图与目标色数的 48×60 像素图并排展示、用户逐图确认后用于关卡已确定；文字、数字、Logo、水印和装饰边框均禁用；原图尺寸待确认。
7. 系列变化：动物、人物、物品题材穿插、避免连续多关过于相似已确认；其他跨关一致性规则尚未设置。
8. 生成流程：模型、候选数量待确认；提示词骨架与验收清单见下文。

## 提示词骨架（依据已确认约束）

> 为像素关卡生成一幅轻松明快的插画。主体为【动物、人物或物品及其组合】，处于【简单装饰背景或简化场景】中。画面保持一个清晰的视觉中心，主体显眼，同时留出可辨认的环境空间。采用【本次选定的画风】，配色明快、颜色区分清楚，避免过多相近色。构图与关键形象特征应在转换为 48×60 像素、【本关目标色数】色后仍清晰可辨。不要纯风景或纯色背景，不使用有版权的知名 IP 角色，不出现文字、数字、Logo、水印或装饰边框。

本关目标色数从对应阶段的已确认范围中选定。提示词中的色数要求不能代替实际转换与色数检查。

## 验收清单

- 批量安排时穿插动物、人物、物品题材，避免连续多关过于相似。
- 内容有一个清晰的视觉中心，整体轻松明快，主体与环境均可辨认。
- 背景为简单装饰或简化场景，不是纯色背景或纯风景。
- 无知名版权 IP 角色、文字、数字、Logo、水印和装饰边框。
- 后续新图的最终像素图为 48×60，实际颜色数量符合对应阶段范围，颜色区分清楚。
- 当前工程与后续图片生成、验收均使用 48×60 网格。
- 原图与像素图并排展示，确认主体及主要形象特征在像素化后得到保留。
- 用户对该图明确确认后，才可用于关卡。
