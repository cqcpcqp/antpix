# 关卡图片生成 Memory

更新时间：2026-11-18

状态：核心约束及 100 关色数阶段已通过问答确认，可用于后续生成。

## 已确认的约束

- 所有关卡图片都使用 AI 生成。
- 主体类型不限于小动物：动物、人物、物品均可；不再将“小动物半身像”作为统一限制。
- 关卡题材交替变化，动物、人物、物品穿插安排，避免连续多关过于相似；不要求按固定顺序循环。
- 2026-11-18 明确重绘候选应避免相似画面：同时对照全部存量关卡和本批候选的主体、动作、场景、构图及配色，不能只换颜色或替换动物就视为新题材。精确重复与感知相似数值只作辅助，最终结合视觉复核。
- 本轮用户指定可使用 Underelay 的 gpt-image-2 重新生成需要重绘的候选；继续复核原图与 48×60 像素图。生成授权不等于将候选自动接入正式关卡的验收。
- 整体氛围保持轻松明快：可以可爱、清新或有趣，不要求所有主体都萌化。
- 画风不限定：扁平卡通、柔和立体绘本、像素风均可，优先满足色数控制与像素化后的辨识度。
- 颜色数量必须受控，以最终用于关卡的像素图为准：前期 10–12 色，中期 13–18 色，后期 19–24 色；按阶段递增，阶段内允许起伏，不要求每关都比上一关增加颜色。
- 第 101–300 关生成时画幅不合格的图片必须重新生成，不裁切；已于 2026-11-14 获用户明确确认。
- 第 101–300 关继续使用 19–24 色，已于 2026-11-14 获用户明确确认。
- 100 关色数阶段：第 1–30 关 10–12 色、第 31–70 关 13–18 色、第 71–100 关 19–24 色。阶段内允许起伏；具体题材与顺序仍须看图验收。
- 配色明快，颜色之间区分清楚，避免过多相近色，方便辨认画面和游戏中选色。
- 像素化后仍应能辨认原图的主体和主要形象特征，不能只看原图好看就通过验收。
- 2026-11-18 用户指出第170关翠鸟的头部过小，像素化后无法辨认。生成与复核必须具体检查主体的识别部位（动物的头、眼、嘴/喙、耳，人物的脸与动作，物品的标志轮廓），不能只检查整体主体占比。不得为分散色块而缩小关键部位；关键轮廓应与背景分离、避免遮挡与近色粘连。最终应在不依赖原图、标题或提示的情况下辨认像素主体；无法辨认则退回，数值改善和可通关不抵消此项失败。
- 每张候选图生成后，展示原图与按对应阶段目标色数转换的 48×60 像素图，进行并排对比；用户看过并明确确认后，才可将该图用于关卡。生成成功或自动检查通过不等于用户验收通过。
- 图片必须有明确主体，不允许纯风景。
- 后续关卡原图按 48×60 的目标网格来设计与验收，构图、主体轮廓和关键细节应优先保证在 48×60 像素化后清晰可辨。
- 每张图保持一个清晰的视觉中心，允许由多个对象共同组成（例如一对动物、一组茶具）；不要求只能有一个对象。
- 构图以显眼的主体为重点，同时留出环境空间；像素化后既能看清主体，也能辨认周围的小场景。不固定具体占比。
- 不接受纯色背景；允许简单装饰背景或简化场景背景，仍须保证主体明确、像素化后可辨认。
- 不接受大块连续同色区域占据主体或背景，尤其避免大片同色海水、天空和主体填充造成长时间重复收集；以最终 48×60 像素图的连通区域为准，不仅检查原图。该要求于 2026-11-17 获用户明确提出。
- 存量关卡图片需补做可玩性审核与难度评级，不符合新要求的图片应重新生成；替换图继续按当前验收流程处理。大色块数值界限和难度分档尚待研究标定，不将初步筛查阈值视为用户已确认标准。
- 2026-11-17 确认游戏难度阶段：第 1–20 关前期（简单）、21–100 关中期（中等）、101 关起后期（困难），新增关卡不改变这些边界。前、中期生成通关路线最多允许两个等待罐，后期最多三个。该难度阶段与既有图片色数分段分别管理；本轮未要求调整色数或重新量化存量图片。
- 不直接使用有版权的知名 IP 角色。
- 不出现文字、数字、Logo、水印或装饰边框，包括题材中的招牌文字、钟表数字等。
- 通过逐轮问答确定其余约束；用户确认后再写入本节，不将建议或历史素材当作已确认要求。

## 后续评估与未设定细则

以下不属于新增硬性约束，不阻碍按已确认要求制作候选图；有必要时再结合具体生成任务或样图确认。

1. 难度阶段：游戏阶段已确认为 1–20 / 21–100 / 101 关起；图片色数仍使用既有 1–30 / 31–70 / 71 关起分段。可玩难度仍需结合像素化效果与试玩评估，色数不等同于实际难度。
2. 构图细则：一个视觉中心、可由多个对象组成，以及主体显眼并留出环境空间已确认；是否额外限定朝向、取景范围和边缘留白待确认，具体占比未设硬性数值。
3. 题材细则：动物、人物、物品各类题材是否有其他限制；整体轻松明快的基调已确认。
4. 背景：简单装饰与简化场景均可，纯色背景已排除；是否随关卡阶段增加背景复杂度待确认。
5. 色彩细则：明快、颜色区分清楚、避免过多相近色及分阶段色数范围已确认；是否限制跨关配色重复待确认。
6. 输出与验收：原图与目标色数的 48×60 像素图并排展示、用户逐图确认后用于关卡已确定；文字、数字、Logo、水印和装饰边框均禁用；原图尺寸待确认。
7. 系列变化：动物、人物、物品题材穿插、避免连续多关过于相似已确认；其他跨关一致性规则尚未设置。
8. 生成流程：模型、候选数量待确认；提示词骨架与验收清单见下文。
9. 可玩结构：限制大片连续同色区域已确认；连通区面积上限、主色占比、遮挡层次与难度评级阈值尚待结合存量审核和规则模拟标定。容器连线玩法尚在讨论，未确认加入。

## 提示词骨架（依据已确认约束）

> 为像素关卡生成一幅轻松明快的插画。主体为【动物、人物或物品及其组合】，处于【简单装饰背景或简化场景】中。画面保持一个清晰的视觉中心，主体显眼，同时留出可辨认的环境空间。采用【本次选定的画风】，配色明快、颜色区分清楚，避免过多相近色。不要用大片连续同色填满海水、天空或主体，让不同物体与环境形成清晰的分区和遮挡，避免长时间只重复收集一种颜色。构图与关键形象特征应在转换为 48×60 像素、【本关目标色数】色后仍清晰可辨。明确保留【本主体的关键识别部位】，使这些部位足够大、轮廓简洁，与相邻背景有明显明暗或色相差异；不要让翅膀、道具或环境挤小头部，不依赖细线、微小眼睛或复杂透视表达主体。不要纯风景或纯色背景，不使用有版权的知名 IP 角色，不出现文字、数字、Logo、水印或装饰边框。

本关目标色数从对应阶段的已确认范围中选定。提示词中的色数要求不能代替实际转换与色数检查。关键部位可以按目标网格估算尺寸来指导本次构图，但尚未确立统一的头宽、眼睛或嘴/喙像素下限，不将单次提示词数值升级为用户确认标准。

## 验收清单

- 批量安排时穿插动物、人物、物品题材，避免连续多关过于相似。
- 内容有一个清晰的视觉中心，整体轻松明快，主体与环境均可辨认。
- 背景为简单装饰或简化场景，不是纯色背景或纯风景。
- 无知名版权 IP 角色、文字、数字、Logo、水印和装饰边框。
- 后续新图的最终像素图为 48×60，实际颜色数量符合对应阶段范围，颜色区分清楚。
- 检查最终像素图的最大同色连通区、主色集中程度及从底部收集时的遮挡关系；主体和背景均不能以大片连续同色区域主导重复收集。具体面积阈值与分档仍待标定。
- 当前工程与后续图片生成、验收均使用 48×60 网格。
- 先隐藏原图、标题及提示，单独查看最终像素图，检查能否辨认主体、关键部位与动作；再与原图并排检查特征是否保留。不能凭已知原图脑补像素内容。
- 对关键部位补看网格放大图，确认头、眼、嘴/喙或标志轮廓真实存在且未粘连；放大仅便于检查，不会补回丢失的像素。主体识别失败须退回，不能用低连通区指标判为合格。
- 用户对该图明确确认后，才可用于关卡。
