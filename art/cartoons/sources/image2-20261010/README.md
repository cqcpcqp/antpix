# 第 1–10 关正式素材

原图由 underelay `gpt-image-2` 生成，用户于 2026-10-10 明确验收。正式关卡为 48×60。

- `manifest.json`：正式顺序、图片名称、色数、验收状态；`file` 为原图，`runtimePixelFile` 为已验收像素图。
- `prompts.jsonl`：当前原图的最终提示词，输出路径相对于项目根目录。
- `review-48x60/*-48x60.png`：关卡数据生成器的输入，必须保留；预览与对照图按需生成，不纳入 Git。

重建流程见项目根目录 `docs/assets.md`。不要在普通重建时重新量化已验收图片。
