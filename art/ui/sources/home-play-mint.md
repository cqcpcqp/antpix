# Mint home action

Implemented from the user's selected, slightly smaller A concept on 2026-10-14.

- `home-play-mint.png`: full-colour production source sheet generated by `gpt-image-2` through the installed codex-image CLI, Images edit mode, 1536×1024, high quality.
- `home-play-mint.txt`: exact generation prompt. The selected A-v2 screenshot was the visual reference.
- `scripts/prepare-home-play.py`: removes the magenta matte and edge spill, crops the three elements, resizes with Lanczos, and exports transparent PNG assets with stable UUIDs.
- `assets/resources/home/play.png`: mint button body, 750×240, displayed at 500×160 logical units.
- `play-start.png` / `play-resume.png`: raised cream lettering, each 495×132, displayed at 330×88 logical units.

Install Pillow and imagequant in a local Python environment, then run `python scripts/prepare-home-play.py`. Runtime images use a perceptually optimized 256-colour palette with minimum quality 85 and light dithering; source art is preserved without palette reduction. At a 375-pixel-wide phone viewport, these assets provide approximately 3× display density. Keep linear filtering and the original aspect ratios; do not stretch the old thin button or substitute plain black labels.

HomeScreen owns the layout and interaction. The main action is centred at 72% of viewport height; navigation artwork is reduced to 110×98 logical units and anchored near the bottom with safe spacing. Reward and cloud retry actions share the gap between the main action and navigation. Start/resume artwork is selected from actual session state; cloud login hides the lettering while showing progress in the button. The level badge remains dynamic text.

`scripts/preview-home.cjs` renders the real node tree offline in deterministic daylight. It is a layout/asset preview, not a browser or WeChat device screenshot.
